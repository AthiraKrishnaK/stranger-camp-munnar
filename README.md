# 🏕️ Stranger Camp — Munnar

A travel platform that connects strangers to explore Munnar together.

## 💡 Idea
Ever wanted to travel but had no one to go with?
StrangeLink lets you join group trips and meet co-travelers!

## ✨ Features
- Browse upcoming Munnar trips
- Connect with fellow travelers
- Trip planning interface

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
